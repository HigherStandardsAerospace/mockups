The gallery and all four concepts use the supplied `Logo-02.png` without recoloring or cropping. The same current artwork is used for browser icons.

All concepts use `#0066B7` as the primary brand blue, with lighter and darker supporting tones for readable text and interaction states.

The index uses actual browser screenshots and opens each self-contained concept. Desktop uses a 2×2 grid; narrow screens use one column. Paths are relative for GitHub Pages hosting under `/mockups/`.

## Preview locally

Run `python3 -m http.server 8768` from this directory, then visit `http://localhost:8768/`.

## Scope

These are design prototypes for review. Precision and The Specialist include the supplied capabilities catalog. Hangar includes two explicitly labeled demo search records. Quote links prepare an email or a local request draft; they do not submit a request automatically.

The Hangar presentation copy includes corrected sample metadata, mobile navigation, a part-aware quote email link and progressive reveal behavior. Original concept sources and existing standalone repositories remain separate.

Only website files and presentation assets are included. Internal briefs and meeting notes are excluded. GitHub Pages serves the root of `main`, with `.nojekyll` to preserve the static file structure.
