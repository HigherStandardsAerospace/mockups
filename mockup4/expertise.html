Before you send a unit

A clear next step.

What should I include in a quote request?+

Start with the part number, quantity, application and unit condition. Add your requested return date and any release documentation requirements so HSA can review the request.

What if my part number is not listed?+

Send the part number and application to HSA. The team will confirm whether the component is within the available scope.

Can I request repair or overhaul?+

Yes. Indicate the service you need, or select “Please advise” in the request form. HSA will confirm the applicable workscope for your component.
